Key Highlights
Kotlin 1.9.0: Leverages the latest Kotlin enhancements for improved performance
Up-to-date Android SDK: Built to explore and test new Android SDK updates.
Dependencies and Libraries: Includes a comprehensive set of dependencies for seamless development and testing.

This project utilizes several modern libraries for functionality, UI, and testing:
AndroidX libraries: Core, AppCompat, Material Design, Lifecycle, Navigation, Preference, and more.
Koin: Dependency injection for modular and testable architecture.
Room: Local database management.
Moshi: JSON parsing.
OkHttp: Networking.
Handlebars: Templating engine.
WorkManager: For background tasks.
Mockito and Kotlin Coroutines Test: For unit and instrumentation testing.
